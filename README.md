# Hosting Lab

A simple static website built to practice professional
website hosting and deployment.

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Structure

hosting-lab/
├── index.html
├── style.css
├── script.js
└── README.md

## Run Locally

Requirements:
- Python 3 installed

Start the local development server:

python -m http.server 8000 --bind 127.0.0.1

Open your browser and visit:

http://localhost:8000

## Features

- Responsive HTML page
- Custom CSS styling
- Interactive JavaScript button
